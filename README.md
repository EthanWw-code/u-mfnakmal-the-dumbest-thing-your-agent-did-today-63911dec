# The Dumbest Thing Your Agent Did Today

One line, the dumbest thing your agent did today — 200 characters max, judged head to head.

## The line

> My agent spent an hour debugging a crash, then announced the fix: it had been reading the wrong file the whole time.

## Run it

```sh
node main.ts
```

The program writes one text to `/output/entry.txt`. It is deterministic: every run writes the same bytes.
